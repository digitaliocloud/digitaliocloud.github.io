NINE Vega Privacy Policy

Effective date: 30 September 2026 · Operator: Petra Malá · Contact: digitalio.cloud@gmail.com

1. Who this applies to

NINE Vega is a private assistant used by one person, its operator Petra Malá, with her own Google account. It is not offered to the public and does not collect data about other users of the app. It does process the content of emails and calendar events in Petra's account, which can include information about the people she corresponds or meets with.

2. Google data accessed and why

PermissionWhat is accessedPurpose
gmail.readonlyEmail messages and metadata (sender, subject, date, content, attachment names)Preparing morning and afternoon briefings of messages needing attention; watching for replies in cases Petra follows.
gmail.composeCreating draft messagesPreparing unsent drafts for Petra's review. Although this permission technically allows sending, NINE Vega sends an email only after Petra explicitly approves that specific message.
calendar.events.readonlyCalendar events (time, title, location, status)Estimating travel and departure times for appointments. NINE Vega never creates, changes or deletes calendar events.

3. How the data is processed and stored

  • Where: on a private virtual server rented by the operator (provider LumaDock, located in Amsterdam, the Netherlands). The server is reachable only through a private network; it hosts no public website or public API.
  • Access token: the Google OAuth token is stored on that server in a file readable only by the NINE service account.
  • Derived data: briefings, short excerpts used to build them and the assistant's working transcripts are stored on the server in local files and a local database. They are currently kept without automatic deletion.
  • Backups: the server's data is backed up daily in encrypted form (restic) to Backblaze B2 cloud storage. Backups are kept for up to 7 daily and 4 weekly snapshots. The storage provider receives only encrypted data.

4. Sharing with service providers

Google user data is not sold, not used for advertising and not shared with anyone other than the service providers needed to run the assistant:

  • OpenAI (AI model API, primary provider): relevant email and calendar content is sent to OpenAI's API to generate summaries and decide what needs Petra's attention.
  • Anthropic (AI model API, secondary provider): configured as a fallback. It processed part of the assistant's conversations between 2 and 21 September 2026 and may again receive the same kind of content when it is used as a fallback.
  • Telegram: briefings and alerts are delivered to Petra's own private Telegram chat with the assistant.
  • Backblaze: stores the encrypted backups described above.
  • Public routing and map services: for journey planning, the location of an appointment may be sent to a public routing or map service to estimate travel time.

NINE Vega does not use Google user data to develop, improve or train generalized AI or machine-learning models.

5. Google API Services User Data Policy

NINE Vega's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Your control and deletion

  • Access can be revoked at any time at myaccount.google.com/permissions; the stored token then stops working.
  • Stored data and derived data can be deleted on request to the contact address above.

7. Changes

If this policy changes, the updated version will be published on this page with a new effective date.
